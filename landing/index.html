SOVEREIGN EXECUTION ARCHITECTURE

Everything Your Terminal Needs to Build, Audit, Transcode & Ship—By Picking a Number.

Most developers waste hours context-switching between chat tabs, documentation, broken virtual environments, and half-finished scripts. Apex Terminal OS unifies the entire software lifecycle inside a single terminal keystroke.

01

12-Ability Startup Command Center

Every time you open a terminal tab (or type m), an interactive numbered dashboard launches. Pick [1]–[12] to trigger any engine, or press ENTER for your standard Zsh prompt.

02

Quote-Free Natural Language Router

Powered by setopt NO_NOMATCH and noglob, type plain English directly into your terminal without quotes—even with ? or *. A 2-stage semantic classifier routes your task to the optimal uncensored model.

03

Self-Healing Hermetic Sandbox

Type sandbox <task>. The engine synthesizes a complete Python, Bash, or TypeScript script, resolves dependencies via uv or bun, runs it live, and automatically repairs and re-runs the code if an error occurs.

04

Live Interactive Visual Canvas Server

Type canvas <ui prompt>. Builds a complete interactive HTML5, Tailwind CSS, and JavaScript application, serves it on localhost:7799, and launches it immediately in your macOS browser.

05

Multi-File Project Forge & runlast

Type forge <spec> to scaffold complete multi-file applications into ~/.apex-workspace/forge/ with an executable run.sh. Plus, every code block generated in chat is auto-saved for instant execution via runlast.

06

500+ Command Fuzzy Arsenal (apex)

Type a to launch an interactive fzf search across 9 curated cheatsheets covering Next.js 15, Hono, Cloudflare Workers/D1, Docker, FFmpeg, yt-dlp, Nuclei, Radare2, and AppleScript automation.
